# J2K Enhanced V8 — شروط التحقق على هاتف أندرويد قبل قبول ترجمة الفقاعات

**الحالة:** هذه قائمة اختبار، وليست ادعاء بأن اختبار الجهاز تم. نجاح GitHub Actions يثبت أن الكود يتجمع ولا يثبت عمل ML Kit على كل مصدر.

## حفظ البيانات أولًا
- احتفظ بإصدار V7 الحالي دون حذف؛ صدّر نسخة احتياطية للمكتبة وسجل القراءة والإعدادات.
- لا تدمج V8 في main ولا تعدل ملفات المانجا المخزنة؛ الترجمة طبقة عرض في الذاكرة.

## اختبار اللغة — أربع عينات فعلية
- [ ] **إنجليزية:** صفحة مانجا عادية بها 3 فقاعات منفصلة، واختيار الإنجليزية، وانتظار تنزيل نموذج اللغة أول مرة.
- [ ] **يابانية:** صفحة نص عمودي وأفقي، واختيار اليابانية، ومراجعة ترتيب العربية ومعنى النص.
- [ ] **كورية:** صفحة بها عدة فقاعات متجاورة، واختيار الكورية، والتحقق من عدم اختلاط النصوص.
- [ ] **صينية:** صفحة بها فقاعة صغيرة وأخرى طويلة، واختيار الصينية، وفحص تكيف حجم الخط.
- [ ] على شبكة بطيئة: يظهر مؤشر واضح ويُبلّغ عن فشل تنزيل النموذج بدل توقف العداد عند صفر إلى الأبد.

## اختبار التنسيقات والواجهات
- [ ] مانجا عادية: موضع العربية فوق النص الأصلي؛ تظهر الخلفية فاتحة دون تغيير ملف الصفحة.
- [ ] Webtoon طويل: تظل الترجمة بمحاذاة النص عند التمرير وفتح/إغلاق الشاشة القابلة للطي.
- [ ] عدّة فقاعات: لكل كتلة OCR ترجمتها الخاصة ولا تختلط بالكتل المجاورة.
- [ ] تكبير وتحريك PhotoView وSubsampling: ترتبط العربية بإحداثيات النص في الصورة ولا تنفصل أثناء السحب.
- [ ] الصفحة الأصلية: إخفاء الترجمة يعيد النص الأصلي فورًا، بدون إعادة تنزيل الصورة.
- [ ] الخط (75–160%) والتعتيم (45–100%) يتغيران بعد الحفظ ويبقيان محفوظين.
- [ ] إعادة المحاولة تترجم الصفحات الفاشلة فقط مع الاحتفاظ بالصفحات الناجحة.
- [ ] في العرض المزدوج يحتفظ التطبيق بإخفاء الطبقة إذا لم تتطابق الإحداثيات بدل وضع نص في صفحة خاطئة.
- [ ] عند توقف المستخدم/تغيير الفصل، لا تظل نتائج فصل سابق فوق صفحات الفصل الجديد.
- [ ] إذا امتلأت فقاعة صغيرة، يستطيع المستخدم فتح «ترجمة الصفحة الحالية» لقراءة النص الكامل.

## شروط الاعتماد
- [ ] GitHub Actions: الفحوص الثابتة واختبارات Kotlin وتجميع Android كلها ناجحة.
- [ ] APK واحد ARM64 موقع للتجربة؛ لا يُعد نسخة نهائية قبل الاختبارات السابقة.
- [ ] جُرّب تحديث التطبيق مع بقاء المكتبة والتنزيلات وبيانات القراءة.
- [ ] الفقاعات ليست محددة حدودها من OCR وحده؛ هذه النسخة تضع العربية فوق موضع النص وتقرب شكل الفقاعة. يلزم كشف حدود بصري مستقل إذا كانت المطابقة التامة للفقاعة مطلوبة.
