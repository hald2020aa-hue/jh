# تحديث J2K Enhanced V9 — حقيقة توافق التثبيت

معرّف حزمة **devDebug** لم يتغير مقارنةً بـ V8:
`eu.kanade.tachiyomi.enhanced.debugJ2K`.
رمز الإصدار زاد من 113 إلى 114، حتى يكون التحديث أحدث.

**لكن لا يكفي تطابق اسم الحزمة ورمز الإصدار**. يرفض أندرويد تحديث تطبيق مثبّت إذا كان مفتاح التوقيع مختلفًا (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`). نسخ GitHub Actions السابقة كانت **Debug** موقعة بمفتاح يمكن أن يتغير مع كل runner. مفتاح التوقيع السابق لا يمكن استنتاجه من APK.

## مسار التحديث الثابت

1. استخدم **مفتاح توقيع خاصًا تملكه أنت** لكل إصدارات J2K Enhanced المقبلة. لا ترسل المفتاح أو كلمات مروره في الدردشة ولا ترفعه إلى المستودع.
2. أضف المفتاح إلى أسرار GitHub Actions، ثم استعمله في **`.github/workflows/v9_stable_update.yml`** يدويًا وعلى فرع `main` المراجع فقط. هذا المسار محظور على طلبات السحب (PR) لمنع تسريب المفتاح. يتطلب أيضًا تثبيت بصمة الشهادة في `JH_UPDATE_CERT_SHA256`. إعداد Gradle يتوقع متغيرات بيئة: `JH_UPDATE_STORE_FILE` و`JH_UPDATE_STORE_PASSWORD` و`JH_UPDATE_KEY_ALIAS` و`JH_UPDATE_KEY_PASSWORD`.
3. تأكد من تطابق معرّف الحزمة والبصمة الرقمية للتوقيع (`apksigner verify --print-certs`)، وأن `versionCode` أعلى من الإصدار المثبّت.
4. إذا كانت النسخة المثبّتة موقعة بمفتاح مختلف، **لا توجد طريقة نظامية لفرض التحديث فوقها**؛ أنشئ نسخة احتياطية من مكتبتك وإعداداتك أولًا، ثم ثبّت نسخة ذات توقيع ثابت مرة واحدة، وبعدها يمكن التحديث فوقها بنفس التوقيع.

بناء GitHub التجريبي لا يُسوّق باعتباره APK قابلًا للتحديث حتى يتم التحقق من شهادة توقيعه. احتفظ بنسختك الموجودة ولا تحذفها قبل التأكد من صحة النسخة الاحتياطية واستعادتها.

## أسرار GitHub المطلوبة لمسار الإصدار المتوافق فقط

- `JH_UPDATE_KEYSTORE_B64`: محتوى ملف مفتاح التوقيع الخاص، بترميز Base64 (لا ترفعه إلى المستودع).
- `JH_UPDATE_STORE_PASSWORD`: كلمة مرور مخزن المفاتيح.
- `JH_UPDATE_KEY_ALIAS`: الاسم المستعار للمفتاح.
- `JH_UPDATE_KEY_PASSWORD`: كلمة مرور المفتاح.
- `JH_UPDATE_CERT_SHA256`: بصمة SHA-256 لشهادة المفتاح الخاصة بك.

مهم: إذا كان التطبيق الحالي مثبتًا بتوقيع مختلف عن هذا المفتاح، فلا يمكن **تحديثه دون إزالته**؛ لا تحذف التطبيق إلا بعد نجاح النسخ الاحتياطي واستعادته والتحقق من بياناته.
